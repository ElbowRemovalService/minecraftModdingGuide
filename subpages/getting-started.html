Getting started

What you need to play with mods, and how the pieces fit together.

The three pieces

  • Launcher: the app you use to start the game and manage profiles.
  • Minecraft version: mods are built for specific versions.
  • Modloader: software that lets the game load mods. Each mod targets one loader.
Rule of thumb: a mod only works if its Minecraft version and loader both match your game.

The order of this guide

  • Pick a launcher
  • Pick a Minecraft version
  • Pick a modloader
  • Find mods and check compatibility
  • Add shaders and resource packs
  • Play with others
